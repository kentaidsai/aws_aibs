重點概念

Key Concepts · Role → Enterprise Strategy → 3D Framework → Technical Foundations
🌉
01

缺口(The Gap)

The Gap

技術、業務、法務團隊各自為政,策略師的角色就是把「我們想要 AI」翻譯成「我們具體要做什麼」。

產品探索案例:模糊的『產品發現壞了』被重新框定為具體、有邊界的問題
📋
02

六大核心職責

Core Responsibilities

策略師負責轉譯野心、評估準備度、內建治理、驗證價值、帶領採用、擴展至企業規模,六者環環相扣、缺一不可。

👂
03

先傾聽,再設計

Listen Before You Design

策略師最重要的能力不是技術,而是紀律地延後給方案,先透過提問把症狀轉成真正的問題。

多問一句釐清問題,勝過急著提早提出的技術方案
🏛️
04

企業策略層(五要素)

Enterprise Strategy Layer

AI Vision(目的地)、Roadmap(路徑)、Portfolio(取捨)三者垂直串接,由 Enterprise Governance 框住,並靠 CxO Engagement 持續提供動能。

AI Vision 是「三年後我們要成為最懂顧客的零售商」,而不是「Q3 上 Bedrock」
⚖️
05

Portfolio:Scale / Pause / Terminate

Scale · Pause · Terminate

依 Business Value、Feasibility、Alignment、Risk 四維度評分後,擴大、暫停、終止三者都是同樣合理且有效的策略選擇。

終止決策必須和啟動一樣『有證據』,而非因沉沒成本逃避
🧭
06

3D 框架總覽

Discover-Design-Deliver

3D 框架把九個步驟收斂成 Discover(搞清楚問題)、Design(架構解法)、Deliver(落地並擴展)三階段,是策略師每天實際使用的執行方法。

Roadmap 決定「下一步做哪個節點」,3D 框架決定「怎麼做這個節點」
🚪
07

Gate 文件:Discovery Readout / Final Report

Gate Documents

階段之間需要正式文件讓 Business、Technical、Compliance 對齊簽核,避免『還沒共識就開始動工』的常見失敗。

Final Report 的 Path to Production 段落是解鎖正式量產資金的關鍵
🪆
08

AI、ML、GenAI 的巢狀關係

AI ⊃ ML ⊃ GenAI

AI 是人寫規則,ML 是系統從資料學規則,GenAI 是系統產生新內容;GenAI 是工具箱的新增項,不是取代 ML 的萬用解法。

詐欺偵測用傳統 ML、通話摘要用 GenAI、審批流程用確定性規則,對號入座
🧠
09

Foundation Model 類型與來源

LLM · VLM · Multimodal · 1P/3P/OSS

依輸入輸出型態分 LLM、VLM、Multimodal,再依 1P(AWS 自建)、3P(透過 Bedrock)、開源(SageMaker)做 build-buy-partner 選型。

LLM 用 Claude on Bedrock;VLM 用 Claude Vision / Nova 2;多模態用 Titan Multimodal
🔄
10

五步驟資料流與資料品質

Data Flow & Data Quality

資料從 Source 經 Storage(S3)、Processing(Lambda)、Model(Bedrock/SageMaker)到 Output,而資料品質才是 AI 專案最常見的失敗原因。

「垃圾進、垃圾出」——模型會忠實處理你餵給它的任何資料
🪜
11

模型調適階梯

Prompt → RAG → Fine-tune → Agent

一律先用 Prompt Engineering,需要專屬資料才加 RAG,需要學會領域模式才微調,需要動態多步驟推理才上 Agent,複雜度與成本依序遞增。

單靠優化提示詞,分類準確率就從 34% 提升到 70%
🤖
12

Agent 與 Autonomy vs. Control

Agents & AgentCore

Agent 能自主規劃、選工具、多步驟執行並依結果調整;用三問測試(後果多嚴重、能否察覺、可否回復)決定該給多少自主權,並用 AgentCore 把 Agent 送上生產環境。

低風險可逆的穿搭建議可高度自主;醫療事先授權須全程人工審核
✓

隨堂測驗考點

Knowledge Checks
Knowledge Check 1
為什麼 Roadmap 的 Phase 2(Capability Building)不能跳過?
✓

因為組織的基礎能力(資料、治理、技能)尚未建立,直接從 Quick Win 跳到 Enterprise Platform 幾乎必然失敗。

Knowledge Check 2
Portfolio 決策中,「終止(Terminate)」代表這個專案失敗了嗎?
✓

不是。Scale、Pause、Terminate 是同樣有效的策略選擇,終止的嚴謹度必須和啟動一樣以證據為準,而非因沉沒成本逃避。

Knowledge Check 3
客戶要做「客服自動化」,是不是一律優先用 GenAI?
✓

不一定。先判斷問題本質再選解法——分類問題用傳統 ML、生成內容用 GenAI、固定邏輯用確定性自動化,不是每個問題都需要 GenAI。

Knowledge Check 4
模型調適(adaptation)該用什麼順序?
✓

一律先從 Prompt Engineering 開始,需要專屬資料才加 RAG,需要學會領域特有模式才考慮微調,動態多步驟工作流才用 Agent。

Knowledge Check 5
判斷一個 Agent 該給多少自主權,要問哪三個問題?
✓

最壞結果有多嚴重、使用者能否在造成傷害前察覺錯誤、錯誤是否可逆——低風險、可察覺、可逆的情境才適合高自主權。

Knowledge Check 6
為什麼資料品質是 AI 專案最常見的失敗原因?
✓

因為「垃圾進、垃圾出」——模型會忠實處理你餵給它的任何資料,所以策略師必須在挑模型之前先確認資料品質。

⭐

一句話總結

AI Business Strategist 的核心價值不是建造 AI,而是在企業策略脈絡(Vision-Roadmap-Portfolio-Governance-CxO)下,運用 3D 框架(Discover-Design-Deliver)確保『對的東西』被建造、被驗證、被採用並能規模化。
